# استودیو نمای سنگی خورشید نو — نسخه موبایل

این پوشه یک وب‌اپلیکیشن استاتیک (PWA) است. برای انتشار آن نیازی به سرور یا نصب برنامه‌نویسی ندارید؛ فایل‌ها را در یک مخزن GitHub قرار دهید و GitHub Pages را روشن کنید.

## امکانات
- پیش‌نمایش ایزومتریک نمای ساختمان نمونه ۴ طبقه
- انتخاب سنگ برای ۳ بخش نمای جلو و ۲ نمای جانبی
- کتابخانه ۱۲ بافت نمونه سنگ
- افزودن عکس سنگ واقعی از گالری یا دوربین گوشی
- تغییر نور روز، غروب و شب
- ذخیره طرح‌ها در حافظه همان مرورگر
- اطلاعات مشتری/پروژه و برآورد مقدماتی مصالح
- خروجی CSV برآورد و ذخیره تصویر پیش‌نمایش با دوبار لمس روی تصویر
- نصب روی صفحه اصلی گوشی و کارکرد آفلاین پس از بارگذاری اولیه

## انتشار با GitHub Pages

1. وارد https://github.com شوید و یک حساب کاربری بسازید یا وارد حساب خود شوید.
2. از علامت + بالای صفحه، گزینه **New repository** را بزنید.
3. در نام مخزن بنویسید `stone-facade-mobile` و حالت **Public** را انتخاب کنید؛ سپس **Create repository** را بزنید.
4. در صفحه مخزن، **Add file → Upload files** را انتخاب کنید.
5. تمام محتویات همین پوشه را انتخاب و در صفحه بارگذاری رها کنید؛ خود پوشه اصلی را داخل مخزن قرار ندهید. باید `index.html` در ریشه مخزن دیده شود.
6. **Commit changes** را بزنید.
7. به **Settings → Pages** بروید.
8. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
9. Branch را روی `main` و Folder را روی `/ (root)` بگذارید و **Save** را بزنید.
10. پس از انتشار، در همان صفحه نشانی وب‌سایت نشان داده می‌شود. نشانی معمولاً شبیه این است:
   `https://YOUR-USERNAME.github.io/stone-facade-mobile/`

## نصب روی گوشی

- **اندروید (Chrome):** نشانی سایت را باز کنید، منوی سه‌نقطه را بزنید و **Install app** یا **Add to Home screen** را انتخاب کنید.
- **آیفون (Safari):** سایت را باز کنید، دکمه Share را بزنید و **Add to Home Screen** را انتخاب کنید.

## نکته مهم درباره نسخه موبایل

این نسخه برای ارائه به مشتری، انتخاب متریال، پیش‌نمایش سریع و برآورد اولیه طراحی شده است. ابزارهای مهندسی نسخه دسکتاپ مانند واردکردن مستقیم فایل‌های Rhino/3DM، ویرایش مش و مدل‌سازی CAD در این نسخه موبایل پیاده‌سازی نشده‌اند. بافت‌های پیش‌فرض، نمونه نمایشی هستند؛ برای نمایش دقیق محصولات کارخانه عکس واقعی هر سنگ را از بخش «افزودن سنگ از گالری گوشی» وارد کنید.

## نکته برآورد

مساحت برآوردی به‌صورت تقریبی از عرض، ارتفاع، عمق ساختمان، درصد بازشوها و درصد پرت واردشده محاسبه می‌شود و مقدار نهایی باید با نقشه اجرایی، بازشوها، برگشت‌ها، پرت واقعی و روش نصب کنترل شود. قیمت‌ها را خودتان وارد کنید.
